# Minecraft Clone

This is a Minecraft clone built with React, Three.js, React Three Fiber, and Cannon.js.

## Features

- First-person movement and camera control
- Block placement and removal
- Texture selection (1-5 keys)
- Physics-based movement and collision
- Persistent world (saved to local storage)

## Controls

- **W, A, S, D**: Move
- **Space**: Jump
- **Click**: Add block
- **Alt + Click**: Remove block
- **1-5**: Select texture (Dirt, Grass, Glass, Wood, Log)

## Development

1. Install dependencies:

    ```bash
    npm install
    ```

2. Run the development server:

    ```bash
    npm run dev
    ```

3. Build for production:

    ```bash
    npm run build
    ```
